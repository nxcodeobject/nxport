Tahu port siapa dijalankan dari folder mana

Fitur

Semua yang Anda butuhkan untuk memahami dan mengelola port di mesin Anda.

Dasbor Interaktif Real-time

Tetap hidup di terminal: navigasi panah, buka browser, kill port, ping, dan refresh — semua dari dasbor. Flicker-free, hanya menggambar ulang saat ada perubahan.

Kolom Dir (Direktori Kerja)

Keunggulan utama: tahu dari folder mana port dibuka — dibaca dari PEB proses (Windows) atau /proc/<pid>/cwd (Linux).

Pencarian Pintar

nxport node atau nxport warkop langsung memfilter berdasarkan nama proses atau folder. Filter rentang port: nxport 8000-8090.

Sniffer Tech Stack

Kenali stack otomatis: [Next.js], [Express], [FastAPI], [Laravel], [Docker], [WSL] — plus deteksi binding publik [PUB!] untuk audit keamanan.

Pengaturan & Server History

Sembunyikan folder tertentu secara permanen, simpan server favorit (folder + perintah start), lalu start/stop langsung dari dasbor.

Siap untuk Script & CI

Mode --once dan -w (watch), ekspor --json/--yaml/--csv, nxport wait (tunggu port up), nxport find (cari port bebas), dan nxport kill <port> -f.

Kontrol Dasbor

Satu tombol untuk setiap aksi — tanpa perlu menghafal perintah panjang.

↑↓Pindah pilih port
EnteroBuka http://localhost:<port> di browser
kxKill proses pada port terpilih
pHealth check port terpilih
sBuka menu Pengaturan
/Cari di daftar port
cUbah urutan (port / pid / process / dir)
rRefresh daftar port
qEscKeluar dari dasbor

Isi Menu Pengaturan (s)

Hide Folder

Sembunyikan port dari folder tertentu — disimpan permanen ke settings.conf dan diterapkan antar sesi.

Server History

Daftar server tersimpan (folder + perintah start) untuk start/stop langsung dari dasbor — terisi otomatis dari port yang sedang berjalan.

System Info

Ringkasan host: nama komputer, OS, serta penggunaan CPU, RAM, disk, dan network di header dasbor.

Show UDP & All TCP States

Tampilkan soket UDP (setara -u) dan semua status TCP, bukan hanya Listen (setara -a).

Refresh Interval

Atur selang auto-refresh daftar port: 1–10 detik (default 2 detik).

Reset All Settings

Kosongkan semua pengaturan: folder tersembunyi, server history, dan preferensi kembali ke default.

API Server

Jalankan/hentikan API internal (default port 7900) langsung dari menu — status running/stopped tampil di daftar.

API Server Port

Ubah port API internal (1024–65535). Port harus dihentikan dulu sebelum diganti.

API Server — akses data via klien

Aktifkan lewat menu Settings (pilih API Server) atau dari terminal, lalu konsumsi dari browser, script, atau tool apa pun:

api — http://localhost:7900
# jalankan API server (default port 7900)
nxport serve
nxport serve 8090     # port kustom

# endpoint yang tersedia
GET /health            # info layanan
GET /api/ports         # daftar port live (JSON)
GET /api/servers       # server history (JSON)
GET /api/stats         # CPU/RAM/Disk/Network (JSON)
GET /api/start/<port>  # start server tersimpan
GET /api/stop/<port>   # stop server tersimpan
Penanda status: 🟢 port sehat/unik · 🔴 duplikat/konflik · [NEW]/[GONE] watch-diff · [PUB!] database terbuka ke publik · [Docker]/[WSL] kontainer

Baris Perintah

Pengganti yang lebih cepat untuk Get-NetTCPConnection dan ss -tlnp.

terminal
# dasbor interaktif (default)
nxport

# filter & pencarian pintar
nxport 8080          # satu port
nxport 8000-8090     # rentang port
nxport node          # filter proses/folder

# untuk script & otomasi
nxport --once        # cetak tabel sekali
nxport --json        # juga: --yaml, --csv
nxport kill 8080 -f  # force kill tanpa konfirmasi
nxport wait 8080     # tunggu sampai port aktif
nxport find          # cari port bebas pertama
nxport -u            # tampilkan UDP
nxport -p            # ping semua port
Integrasi NxCode IDE: port dari editor.exe otomatis dipetakan ke folder proyek aslinya via QSettings IDE — jadi kolom Dir menampilkan D:/Website/Tatiye, bukan folder instalasi.

Cara Pasang

Build dari source — tanpa dependensi pihak ketiga.

Windows · MSVC
git clone https://github.com/nxcodeobject/nxport
cd nxport
./build.bat          # menghasilkan nxport.exe

# tambahkan ke PATH user:
$dir = 'D:\CLI\NxPort'
$p = [Environment]::GetEnvironmentVariable('Path','User')
[Environment]::SetEnvironmentVariable('Path',
  ($p.TrimEnd(';') + ';' + $dir), 'User')
Linux · g++
git clone https://github.com/nxcodeobject/nxport
cd nxport
./build.sh           # menghasilkan nxport
sudo install -m755 nxport /usr/local/bin/nxport

Butuh Visual Studio (workload Desktop development with C++) di Windows, atau g++ di Linux. Baris dengan tanda “-” berarti proses tidak bisa diperiksa — jalankan sebagai administrator/root agar lebih banyak yang terbaca.
